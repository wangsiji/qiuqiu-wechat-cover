<h1 align="center">qiuqiu-wechat-cover</h1>

<p align="center"><b>把你的公众号文章，直接交给 AI，生成统一、好看的公众号封面</b></p>

---

## 👋 这是干什么的？

如果你平时写公众号，可能会遇到一个问题：

> **文章写完了，封面怎么办？**

你可能会：

- 不知道封面写什么字
- 每次生成出来的风格都不一样
- 人物一会儿长这样，一会儿又变样
- 产品照片被 AI 改得面目全非
- 明明只想改一个地方，结果整张图都变了
- 生成了很多张，却很难选出一张能直接用的

**qiuqiu-wechat-cover 就是帮你解决这些问题的。**

你不需要学习设计，也不需要学习 Prompt。

你只需要把文章和图片交给智能体，然后告诉它：

> **“帮我做这篇文章的公众号封面。”**

剩下的事情，让 AI 来完成。

---

# 🚀 最简单的使用方法

## 第一步：把这个 Skill 安装到你的智能体

把这个项目安装到你使用的 AI Agent / 智能体中。

安装好以后，**不需要打开代码，也不需要自己运行命令。**

直接在智能体里使用即可。

---

## 第二步：第一次使用时，AI 会问你两个问题

第一次使用这个 Skill，智能体会先帮你完成一次简单设置。

### ① 你想用谁作为封面人物？

你可以选择：

**使用默认人物**

适合直接使用这个项目自带的「秋秋」人物形象。

或者：

**换成你自己的照片**

你只需要把一张人物照片发给智能体。

以后做封面时，AI 会尽量保持这个人物的脸型、五官、发型和整体身份一致。

> **这个设置只需要做一次。**
>
> 以后不用每次重新上传人物照片。

---

### ② 你要不要使用 Lovart 来生成图片？

如果你的智能体已经连接了 Lovart，直接选择使用即可。

如果还没有配置，也可以先跳过。

**第一次使用时 AI 会告诉你需要做什么，不需要自己研究配置文件。**

如果需要 API Key，**不要把 Key 发到聊天里，也不要写进 GitHub 仓库。**

---

# 📝 第三步：把文章交给 AI

之后，你就可以像平时聊天一样使用。

例如直接说：

> **帮我给这篇公众号文章做一个封面。**

然后把文章发给智能体。

如果文章里有需要准确展示的东西，也一起发：

- 人物照片
- 产品照片
- Logo
- 旅行照片
- App 截图
- 网页截图

**不需要自己告诉 AI 应该怎么排版。**

---

# ✏️ 第四步：AI 会先和你确认封面文字

AI 不会一上来就直接生成。

它会先帮你从文章里找到适合放在封面上的内容，并给你几个简单的方案。

例如：

> **方案 A**
>
> 100件长期好物  
> 戴了6年还在戴

你觉得可以，就告诉它：

> **“就用这个。”**

然后 AI 才会开始生成。

这样可以避免一个很常见的问题：

> **图片生成好了，结果封面上的中文字写错了。**

---

# 🎨 第五步：AI 自动处理设计

确认以后，AI 会自动完成：

- 选择适合文章主题的构图
- 安排标题位置
- 使用统一的视觉风格
- 保持人物形象
- 保护产品、Logo 等真实素材
- 控制封面比例
- 检查有没有出现不应该出现的文字

你不需要学习这些规则。

**这些都是这个 Skill 内部负责的事情。**

---

# 🔍 第六步：生成以后，AI 还会自己检查

图片生成出来以后，不代表任务就结束了。

AI 会继续检查：

### 人物有没有变？

比如你提供的是同一个人，AI 会检查有没有出现明显的换脸、脸型变化等问题。

### 产品有没有被改掉？

如果你提供了一双鞋、一件衣服、一个包，AI 会尽量保持它原本的外观，而不是重新“设计”一个。

### Logo 有没有变形？

Logo 属于需要高度准确的素材，会重点保护。

### 文字有没有多出来？

封面最终出现的文字，应该来自你确认过的内容。

### 整体好不好看？

还会检查：

- 构图
- 层次
- 明暗
- 风格
- 和文章主题是否匹配

---

# 🔄 如果第一次不满意怎么办？

**不用重新从头开始。**

你可以直接告诉 AI：

> “人物脸变了。”

或者：

> “产品变形了。”

或者：

> “标题太小了。”

或者：

> “整体太暗了。”

AI 会根据你的反馈，只修改对应的问题。

例如：

**你说：**

> 产品变形了，其他都保持不变。

**AI 会尽量：**

> 只加强产品保护，不重新改变人物、文字和整体构图。

这就是这个 Skill 很重要的一点：

> **哪里有问题，就改哪里。**

---

# 🧠 为什么它比“直接让 AI 画一张图”更稳定？

因为这个 Skill 在后台帮你记住了几件重要的事情。

### ① 记住你的视觉风格

不会今天一个风格，明天又换一个风格。

### ② 记住你的封面人物

不会每篇文章都重新“猜”一次人物长什么样。

### ③ 记住哪些东西不能乱改

例如：

- 产品
- Logo
- 人物
- 旅行照片

### ④ 记住你确认过的文字

不会 AI 自己随便往封面上加字。

### ⑤ 记住上一次哪里出了问题

下一次修图时，可以针对问题继续优化。

---

# 🎯 你只需要负责三件事

整个过程中，你真正需要做的事情其实很少：

### ① 提供文章

告诉 AI：

> “这是我要发布的文章。”

### ② 确认封面文字

AI 给你几个方案，你选一个。

### ③ 最后看一眼

如果满意：

> **“可以，用这张。”**

如果不满意：

> **“人物不对。”**

> **“产品变形了。”**

> **“标题再大一点。”**

就这么简单。

只要是公众号文章，都可以让它先帮你分析适合什么样的封面。

# 👤 如果我是第一次使用，应该怎么说？

最简单的一句话：

> **“帮我给这篇公众号文章生成一个封面。”**

然后把文章发过去。

如果需要人物：

> **“人物用我刚刚上传的这张照片。”**

如果有产品：

> **“这个产品必须保持原样。”**

如果你不喜欢第一次结果：

> **“人物变了，其他保持不变，再生成一次。”**

**你不需要告诉 AI 应该怎么写 Prompt。**

---

# 🎨 默认封面风格

这个项目目前内置的是「秋秋很开心」的视觉体系：

- 暖木色
- 复古像素
- 温馨工作台
- 明亮
- 温暖
- 生活化

封面比例统一为 **2.35:1**，推荐尺寸 **1880 × 800**。

如果你使用自己的账号，也可以根据自己的品牌重新设置人物、风格和素材规则。

---

# 🔐 关于隐私和 API Key

如果使用图片生成服务，可能需要 API Key。

请记住：

> **API Key 是密码，不要直接发到聊天里。**

这个 Skill 的设计原则是：

- 不把 Key 写进仓库
- 不把 Key 放进 README
- 不把 Key 放进 Prompt
- 不把 Key 暴露给其他人

如果你的智能体需要配置 API Key，它会告诉你应该在哪里配置。

# ❓ 常见问题

### 我完全不会写代码，可以用吗？

**可以。**

如果你只是使用这个 Skill，正常情况下你不需要看代码。

你只需要在智能体里聊天。

---

### 我不会写 Prompt，可以用吗？

**可以。**

Prompt 是这个 Skill 在后台帮你处理的。

你只需要说你想要什么。

---

### 每次都要重新上传人物照片吗？

**不需要。**

第一次设置好以后，就作为默认人物使用。

如果以后想换人物，再告诉智能体即可。

---

### 我可以使用自己的品牌风格吗？

**可以。**

这个项目并不限制你必须使用「秋秋很开心」的视觉。

你可以替换：

- 人物
- 风格参考
- Logo
- 产品素材
- 封面规则

---

### 如果 AI 第一次生成不好怎么办？

直接告诉它哪里不好。

例如：

> “人物不像。”

> “产品变形了。”

> “标题太小。”

> “颜色太暗。”

> “这个构图太拥挤。”

**不用自己重新描述一大堆要求。**
