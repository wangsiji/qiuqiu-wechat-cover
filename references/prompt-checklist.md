# 秋秋公众号封面验收清单

## 生成前

### 文章与模式

- [ ] 已读取完整文章；主题、点击理由、核心数字/结果/冲突有正文依据
- [ ] 已确认模式：新封面或编辑已有封面

### 内置资产

- [ ] `references/assets/qiuqiu-face-reference.jpg` 真实存在且可读取
- [ ] `references/assets/qiuqiu-style-reference.png` 真实存在且可读取
- [ ] `python3 tools/resolve_assets.py` 返回 `ok: true`
- [ ] 身份 JPG 与风格 PNG 文件头有效（非损坏文件）

### 图像输入

- [ ] 图 1（身份）已作为真实 image input 传给图像工具
- [ ] 图 2（风格）已作为真实 image input 传给图像工具
- [ ] 不只是把文件名/路径写进提示词
- [ ] 当前任务素材（如有）从图 3+ 开始编号
- [ ] 用户指定新的真人参考时，确认过它替换的是 图 1；其余新图不覆盖默认资产

### 文案

- [ ] 文案已确认：1 个小钩子 + 1 个主标题 +（可选）1 句补充
- [ ] 总文字约 20～35 个汉字，未塞功能清单
- [ ] 提示词写明 2.35:1、推荐 1880×800、逐字正确、不得添加未授权文字

### 禁止条件

以下任一项不满足就不得生成正式封面：

- 内置身份图或风格图未真实加载/注入
- 必要的真实素材缺失（无文字名/留白替代可用）
- 文案未确认

## 失败原因分类（Failure Codes）

验收不通过时，判 `F##`，**只修对应一层**，不全文重写：

| Code | 失败 | 只修 |
|---|---|---|
| F01 | 人物身份漂移 | identity 层（Image 1 / 冻结特征） |
| F02 | 中文错字 / 多余文字 | Copy Lock（allowed_text） |
| F03 | 产品变形 | asset fidelity（升到 level 2/3） |
| F04 | Logo 失真 | asset fidelity（level 3） |
| F05 | 构图拥挤 / 比例失衡 | layout 模板或 category |
| F06 | 主题不明确 | content.category / topic |
| F07 | 画面过暗 | style-guide 光线段 |
| F08 | 出现未授权文字 | NEGATIVE + allowed_text |
| F09 | 比例错误 | cover.ratio / 尺寸 |
| F10 | 风格漂移 | style-guide 固定段 |

流程：`生成 → 失败归类 Fxx → 只改对应段 → 重跑 → 回归检查(F01-F10 全过)`。

## 生成后

- [ ] 实际尺寸和比例正确（2.35:1）
- [ ] 只看封面能推出正文主题
- [ ] 中文逐字正确、无漏字；重点数字无误
- [ ] 真人仍是秋秋：脸型、五官、黑发、肤色、年龄感正确
- [ ] 默认口罩仍在（除非用户明确要求摘除）
- [ ] 未卡通化、换脸、过度美颜、完全像素化
- [ ] 产品、Logo、包装、旅行照未被重绘、换色或替换
- [ ] 标题、人物、产品没有相遮挡；画面明亮温暖
- [ ] 没有未授权人物、产品、Logo、地点或装饰文字
- [ ] 局部编辑只改了用户点名区域，其他区域一像素未动
- [ ] 输出文件在项目目录之外，未写入或提交到仓库

不确定的项目标记「待确认」，不要用“看起来应该正确”代替检查。
